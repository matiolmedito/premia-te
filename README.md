# premia.te

Primera versión del sitio web de **premia.te**.

## Estado
Prototipo funcional inicial. Todavía no procesa pagos ni almacena datos reales.

## Incluye
- Landing responsive
- Sorteo inicial: iPhone 17 Pro 256 GB
- Selector de 2.000 números
- Precio demostrativo de Gs. 10.000
- Buscador y selección aleatoria
- Página de bases y condiciones en borrador
